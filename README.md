# Corrective feedback and security-monitor carry-over

A 2 × 2 study of low versus balanced violaiton targets alongside manipulations of neutral acknowledgement or feedback. Repo includes task scripts and analysis. 

## Setup

Uses Python 3.12 and an ADAPTION_API_KEY (set as an environment variable) and all analysis was run using Qwen-3.8-27B [See Adaption model list](https://docs.adaptionlabs.ai/inference-stacks/models).
